## 🌴 What is HH Goa ID Studio?

**HH Goa ID Studio** is a fast, mobile-first identity generator built for the **Hacker House Goa 2026 Frame / ID Card Challenge**.

It transforms an ordinary photo into a personalized HH Goa 2026 visual identity in seconds.

Choose your format, add your builder details, customize the visual treatment, and generate a share-ready graphic.

> **Your photo. Your stack. Your builder identity.**
